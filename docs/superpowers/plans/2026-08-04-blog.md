# Blog Listing + Single Post Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pixel-perfect clone of ivycleans.com's `/blog` listing (page 1, spam card excluded) plus the full "Do I Need to Be Home During a Deep Cleaning Service" post page.

**Architecture:** Both pages join the `(inner)` route group (verified: live blog pages use the same header-47/footer-186 chrome as rounds 2–3). One data module feeds a card-grid listing component and a structured-blocks article renderer. The comment form is display-only.

**Tech Stack:** Next.js 16.2.12 (App Router, static), React 19, Tailwind 4, TypeScript, pnpm.

## Global Constraints

- AGENTS.md conventions binding: font-size ladder; explicit arbitrary rem values traced to `post-32.css` (listing) / `post-952.css` (post template) in `docs/superpowers/reference/ivycleans-live/`; Poppins; U+2019 apostrophes in JSX (`&rsquo;`/literal ’, never straight `'`).
- Copy verbatim from `blog-content-dump.txt` / `blog-post-content-dump.txt` — BUT the listing dump concatenates each card's date/comment footer into the NEXT card's heading line. Card-level data (title, href, excerpt, category, date, comment string, thumbnail) MUST be extracted per `<article>` block from the raw `blog.html`, not eyeballed from the dump. Preserve quirks ("Breakfrom your routine" missing space, excerpts cut mid-sentence).
- **SPAM EXCLUSION (user ruling):** the live listing's first card — "Maintaining a Clean Gaming Environment: Vavada Casino's Approach to Digital Hygiene" → /vavada-casino/ — is injected spam and must NOT appear. Our listing renders the 8 legitimate cards. grep gate: "vavada" absent from rendered output.
- Card hrefs are LOCAL site-relative slugs (e.g. `/how-to-clean-bathroom-walls`); only the built post resolves. Pagination links verbatim from the live hrefs: `/blog/2/`, `/blog/3/`, `/blog/4/`, `/blog/5/` (NOT `/blog/page/N/` — the spec's guess was wrong; the reference HTML governs), dead until later rounds.
- Post page metadata verbatim: title "Do I Need to Be Home During a Deep Cleaning Service - Ivy Cleans" + full description from blog-post.html's meta tag. Listing metadata: title "Blog - Ivy Cleans" + its live description if present (check blog.html; if the live page has no description meta, omit the field).
- **Only prior-round file that may change: `src/data/posts.ts`** (three absolute URLs → local slugs). Front page re-verified by byte-diff with ONLY those three href values differing. No other shared file edits.
- Next 16: no `priority`; no `dynamic`/`revalidate`; lint run separately.
- Commit per task with given message + trailer `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
